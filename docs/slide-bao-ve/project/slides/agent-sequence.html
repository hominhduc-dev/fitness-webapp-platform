(Khoảng 25 giây) [Lời thoại] Sơ đồ này cho thấy các bước khi Agent điều chỉnh giáo án, thầy cô đọc từ trên xuống. Người dùng nhờ Agent xem lại giáo án, Agent đọc dữ liệu rồi tạo một đề xuất, nhưng chưa sửa gì cả. Chỉ khi người dùng bấm duyệt thì thay đổi mới được áp dụng. [Nếu hỏi: Về kỹ thuật thì diễn ra thế nào?] API trả về mã 202 kèm mã lượt chạy; worker gọi tool propose_program_changes để lưu đề xuất kèm fingerprint giáo án và hash, hạn 24 giờ; khi duyệt, người dùng gửi kèm payloadHash; worker tiếp tục từ checkpoint và gửi kết quả qua SSE.
